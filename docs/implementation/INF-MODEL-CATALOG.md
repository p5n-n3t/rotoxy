# Inference provider model catalog

The authenticated inference provider admin page can explicitly refresh `/models` metadata for an existing enabled OpenAI-compatible account. Refresh requires the admin session and CSRF token, uses the account's saved credential and its fixed or previously validated HTTPS origin, and performs one bounded GET with redirects disabled. Custom origins go through the pinned public-provider transport with public DNS validation; that transport permits GET only when its caller opts in, while all existing callers remain POST-only. The response is limited to 2 MiB and 2,000 entries; oversized catalogs fail visibly instead of being silently truncated. Credentials and provider response bodies are never logged or persisted.

The searchable checkbox picker is a UI for editing the existing exact `allowedModels` policy. Catalog refresh never selects models or changes the saved policy. Existing selections remain visible and checked if a provider no longer lists them. Empty selections continue to deny inference, and the existing 200-model allowlist limit remains in force. Manual ID editing remains available.

OpenRouter [`GET /api/v1/models`](https://openrouter.ai/docs/client-sdks/typescript/api-reference/models/models) metadata supplies per-model `pricing.prompt` and `pricing.completion`. “Zero prompt and completion pricing only” includes a model only when both values use valid decimal syntax and represent exact zero; missing, malformed, or nonzero values are excluded. A `pricing.request` charge, when supplied, must also be exact zero. Hex strings and positive values that underflow JavaScript numeric precision remain unconfirmed and are excluded. This is metadata from the provider, not a guarantee of future availability, eligibility, or total request cost. OpenAI and custom endpoints do not receive a free classification from this UI.

Focused coverage is in `test/provider-model-catalog.test.mjs` and `test/public-provider-http.test.mjs`. Tests use synthetic responses and credentials; no live provider call is required.
