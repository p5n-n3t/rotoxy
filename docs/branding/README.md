# Branding assets

The Token2OAuth logo is the relay-gate mark: three routed lanes pass through a frame and meet at one supervised node. Use `../../assets/brand/logo.svg` for general mark usage, `favicon.svg` for browser tabs, and `social-banner.svg` for link previews.

Use the product name exactly as **Token2OAuth**. Do not substitute partner names or an operational page title for the product identity. Keep clear space around the mark approximately equal to the node diameter. On light surfaces the logo uses ink `#16191d` and signal `#0f7b6c`; the favicon reverses the frame on a dark tile. Do not recolor the signal node as a warning indicator.

The dashboard's live inline logo adapts to light and dark themes. SVG exports are static and intended for branding contexts. See the repository-root `DESIGN.md` for palette tokens, responsive composition, and accessibility behavior.
